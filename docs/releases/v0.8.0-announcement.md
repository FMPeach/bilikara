## 中文

标题：bilikara v0.8.0 稳定版

bilikara v0.8.0 稳定版现已发布。本版更新了原生桌面后端、手机播放控制和来源管理，并集中修复了缓存、启动、更新与全屏体验。

- 桌面版默认使用 Rust Host，安装包不再包含 Python。
- 支持常见 YouTube 单视频链接；本场用户可改名、多选和批量排序，手机身份同步名称。
- Host 来源页支持持久化排序和批量移除，拉取期间仍可管理；等待拉取的收藏夹可以进入查看状态。
- 增加重唱：Host 直接点击；手机竖屏长按切歌向左展开，点选或拖到重唱后松手执行。播放抽屉支持滑动展开／收起。
- 修复 HiRes 切换导致缓存卡住。HiRes 与清晰度均在新建下载任务时生效，不自动中断／重下已有任务。
- 修复启动时自动检查更新和偏好保存；改善继续上一场、原生全屏、双屏提示及 Remote 重连。
- 升降调使用 Signalsmith Stretch；增加默认关闭、需 Host 设定基准的自动音量实验。

**从 v0.8.0-preview.2 及更早版本升级，请备份数据后下载完整包，不使用旧版软件内更新。** Windows Preview 2 保留整个 `runtime` 文件夹；macOS 保留 `~/Library/Application Support/bilikara/`。更早版本按提示导入旧数据，详见[升级说明](https://github.com/VZRXS/bilikara/blob/dev/docs/upgrading.md)。

Android 继续作为预览版。公网连接新增分阶段提示与可选 TURN 配置接口；TURN 仍需独立服务配套与管理员启用，不代表公共 Wi-Fi／AP 隔离问题已在线上解决。

[下载完整包](https://github.com/VZRXS/bilikara/releases) · [使用说明](https://github.com/VZRXS/bilikara/blob/dev/docs/quick-start.md)

## English

Title: bilikara v0.8.0 stable

bilikara v0.8.0 stable is now available, with a native desktop backend, improved mobile playback controls and source management, and fixes for caching, startup, updates and fullscreen playback.

- Desktop packages now use the Rust Host by default and no longer include Python.
- Request common YouTube single-video links. Rename, select and reorder session users on the Host, with names synchronized to bound phones.
- Save source order and remove sources in batches while pulls continue. Open queued favorites to see their status.
- Restart the current song directly on desktop. On a portrait phone, hold Next to reveal Restart, then tap it or slide onto it and release. Swipe the playback sheet open or closed.
- Fix HiRes changes leaving caching stuck. HiRes and quality changes apply to newly created downloads, without automatically interrupting or redownloading existing tasks.
- Fix startup update checks and preference persistence; improve session resumption, native fullscreen, audience notices and Remote reconnection.
- Pitch shifting uses Signalsmith Stretch. Optional automatic volume remains experimental, off by default, and requires an explicit Host reference.

**Upgrading from v0.8.0-preview.2 or earlier requires a complete package after backing up your data. Do not use the old in-app updater for this transition.** On Windows Preview 2, preserve the entire `runtime` folder; on macOS, retain `~/Library/Application Support/bilikara/`. Earlier versions use the confirmed import flow. See the [upgrade guide](https://github.com/VZRXS/bilikara/blob/dev/docs/upgrading.md).

Android remains a preview. Internet Remote gains connection-stage messages and an optional TURN configuration interface. Relay activation still requires the independent signaling service and administrator setup; this release does not establish that public Wi-Fi or AP isolation is fixed in production.

[Download the complete package](https://github.com/VZRXS/bilikara/releases) · [Usage guide](https://github.com/VZRXS/bilikara/blob/dev/docs/quick-start.md)

## 日本語

タイトル：bilikara v0.8.0 安定版

bilikara v0.8.0 安定版を公開しました。デスクトップのネイティブバックエンド、スマートフォンの再生操作、ソース管理を更新し、キャッシュ・起動・更新・全画面表示の不具合を修正しました。

- デスクトップ版は標準で Rust Host を使用し、Python を同梱しません。
- 一般的な YouTube 単一動画リンクに対応。Host で参加者の名前変更・複数選択・一括並べ替えができ、紐付いたスマートフォンにも名前が同期されます。
- ソースの取得中も並べ替え・一括削除ができ、順序は再起動後も保持されます。取得待ちのフォルダーも開いて状態を確認できます。
- デスクトップに最初から歌い直すボタンを追加。スマートフォンの縦画面では「次の曲」を長押しし、左に開いた歌い直しボタンをタップ、または指を滑らせて離すと実行します。再生パネルはスワイプで開閉できます。
- HiRes 切り替え後にキャッシュが止まる問題を修正。HiRes と画質は新しいダウンロードタスクから適用し、既存タスクの自動中断・再取得は行いません。
- 起動時の更新確認と設定保持を修正。前回セッションの継続、ネイティブ全画面、観客画面の通知、Remote の再接続を改善しました。
- キー変更に Signalsmith Stretch を使用。自動音量は既定でオフの実験機能で、Host で基準を明示的に設定します。

**v0.8.0-preview.2 以前からの更新は、データをバックアップして完全パッケージをダウンロードしてください。今回の移行には旧版のアプリ内更新を使用しないでください。** Windows Preview 2 は `runtime` フォルダー全体、macOS は `~/Library/Application Support/bilikara/` を保持します。それ以前の版は確認付きのインポートを利用します。[更新手順](https://github.com/VZRXS/bilikara/blob/dev/docs/upgrading.md)をご覧ください。

Android は引き続きプレビュー版です。公開 Remote に接続段階の表示と任意の TURN 設定インターフェースを追加しましたが、中継の有効化には独立したシグナリングサービスと管理者の設定が必要です。公共 Wi-Fi や AP 分離の問題が本番環境で解決済みという意味ではありません。
